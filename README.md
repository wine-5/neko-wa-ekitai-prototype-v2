# 『猫は液体』プレイアブルHTMLプロトタイプ

## 起動

`prototype/index.html` をエクスプローラーからダブルクリックすると、ブラウザで直接遊べます。タイトル画面の「ステージを選ぶ」からステージを選び、「プレイする」でゲーム画面に進みます。起動だけならNode.jsやHTTPサーバーは不要です。

ローカルHTTPサーバーで開く場合は、この `prototype/` フォルダーで次を実行します。

```powershell
npm start
```

PCブラウザで <http://localhost:8000/> を開いてください。依存パッケージは不要です。`npm start` は直接起動用スクリプトを自動更新します。Pythonが使える環境なら `python -m http.server 8000` でも起動できます。

`src/` のJavaScriptを編集した後にファイルから直接開く場合は、`npm run build:offline` で `src/game-classic.js` を更新してください。

自動検証は `npm test` で実行できます。

## 操作

- `Space` 長押し：重力を強めて地形へ押し付ける。空中では早く落ちる。
- `Space` を離す：空中では弱い重力で滑空します。最初のジャンプ台の「SPACE を離す」の印付近で解放し、着地まで離したままにすると連続10秒以上飛べます。平地で離しても固定ジャンプは起きません。
- `Esc`：ポーズ／再開。
- マウス左ボタンをゲーム画面上で長押ししても同じ操作ができます。
- メニューはマウスまたはキーボードで操作できます。残機があるミスでは3秒のカウントダウン後に自動で再挑戦します。

## 音量設定

タイトルの「設定」とポーズ中の「音量設定」から、BGMとSEをそれぞれ0〜100%で調節できます。「戻る」または`Esc`で元の画面へ戻り、ポーズから開いた場合はゲームを止めたまま戻ります。変更はその場で反映し、ブラウザの`localStorage`に保存します。初期値はBGM 40%、SE 65%です。SEは「SEを試す」ボタンで確認できます。

現在のBGMとSEは`src/audio.js`で作る仮音です。ブラウザの再生制限により、最初にボタンやスライダーを操作した後に鳴り始めます。完成版の楽曲・効果音素材ではありません。

## 実装範囲

1ステージ、タイトル・ステージ選択・プレイ・ポーズ・ミス・魔女の仮演出・リザルトを含みます。本は3冊で、回収数に関係なく出口に着けばクリアです。3冊回収時のみ魔女の仮演出に進みます。

プレイ画面左上の「飛距離」「上昇」はジャンプ中に更新し、着地後は直前のジャンプ結果を表示します。「最長滞空」は1回の飛翔で連続して空中にいた最長時間を示し、10秒達成で色が変わります。リトライ時には消去します。距離・高度の単位はCanvasのワールド座標pxで、完成版のスコアではなく飛翔テスト用の表示です。

### コイン・スコア・残機

坂に月の刻印コイン60枚を配置しました。取得で100点、50枚ごとに1UPします。残機は3から開始し最大9です。飛翔が0.5秒以上続いた場合、着地時に滞空時間・飛距離・着地速度の点を加えます。配点とコイン座標は`src/config.js`の暫定値です。

ミス時は残機を1減らし、合計スコアと次の1UPまでのコイン数を保持します。残機があれば3秒後に自動で再挑戦し、本とコインを再配置します。ミス画面から待ち時間を短縮する操作はありません。残機0でゲームオーバーになり、「最初から」で3機・0点に戻ります。ポーズからの手動やり直し、ステージ選択からの再プレイ、クリア後の再挑戦も新しいゲームです。

プレイ中のHUD上部には、ミスをまたいで保持する「合計スコア」だけを表示します。現在の挑戦で獲得した点数はクリア後のリザルトに表示します。ステージ最高スコアは**クリアした挑戦1回分**だけで判定し、ブラウザの`localStorage`へ保存します。ミス前の得点を積み上げても最高記録には含まれません。旧方式の最高記録とは別の保存キーを使います。進行中のゲームはページ再読み込みでリセットされます。

接地中に実際に左へ動き始めた瞬間は「逆走」のミスになり、残機が1減ります。地上の低速が連続1.0秒続いた場合も従来どおりミスです。停止危険ゲージは後者の残り時間を示します。空中で左へ移動しても逆走ミスにはしません。

物理と地形の数値は `src/config.js` に集約した試作用の仮値です。地形の曲線、衝突、飛翔の計算は `src/physics.js`、カメラの追従とズームは `src/camera.js` にあります。全回収記録はページを開いている間のメモリにだけ保持します。

上り坂で離した瞬間は、坂の接線方向の速度と移動速度に応じた上向き補助を使います。空中の猫が地形の表面へ入った場合はそのフレームで接触を解決し、穴の内側から着地斜面へ横入りした場合は穴の縁で止めます。上昇中は地形との高度差に合わせてカメラを引き、画面内に猫と地形を収めます。

### 新しいステージ地形

ステージは22,000pxです。序盤の長い下り坂とジャンプ台を残し、その先の5,400pxの空白を連続する山と谷に置き換えました。高さが交互に変わる起伏の上を約10秒滑空できます。後半にも山谷が続き、13,300–15,000pxの穴で2回目の飛翔を試せます。3冊目は2回目の着地後に配置しました。坂上の「長押し」「離す」の印は操作タイミングの目安です。地形の中間点は滑らかな曲線でつないでいます。

### 主な暫定値

| 項目 | 値 |
|---|---:|
| ステージ終端 | 22,000 px |
| 初速 / 最高速度 | 600 / 950 px/s |
| 地上通常 / 空中解放 / 長押し重力 | 900 / 125 / 1,400 px/s² |
| 地上 / 空中の抵抗係数 | 0.08 / 0.005 |
| 低速閾値 | 55 px/s |
| 低速死亡までの連続時間 | **1.0秒（確定）** |
| 猫 / 本の当たり判定半径 | 19 / 28 px |
| 物理更新間隔 | 1/120秒 |
| 滞空目標 | 連続10秒 |
| カメラの猫位置 / 最小ズーム | 画面幅の34%、上昇中の縦位置38% / 0.24倍 |
| カメラの高度フレーミング / 追従係数 | 380px / ズーム3.5・水平7・垂直6 |
| 頂上での発射補助 | 曲率係数0.09、曲率閾値0.003、速度に応じ最大350 px/s |
| 長押しを離した時の発射補助 | 上り傾斜が-0.25より急、速度220 px/s以上。坂の接線速度に、移動速度の0.2倍（最大130px/s）の上向き分を加える |
| 着地後の速度係数 | 接線方向への投影後に1.2倍 |
| 穴 | 13,300–15,000 px |
| 本のX位置 | 1,700 / 9,650 / 21,500 px |

上記は物理・ステージの調整用で、企画の確定値ではありません。最初のジャンプ台の目印付近（x≈2,860）で離し、着地まで空中で押さない試験経路では、最初の飛翔が連続10.33秒・約6,372px、2回目の飛翔が11.32秒です。カメラは最大0.24倍まで引き、猫を画面内に収めます。3冊を回収し約32.8秒でクリアします。x≈2,840〜2,900で離した試験経路でも最初の10秒以上の滑空と全回収クリアを確認しました。空中で押すと落下が速くなり、飛距離が短くなります。

## 次段階のUI素材

採用した「月の刻印」コインと、B案の描き込まれた質感に合わせたUnity向け透過PNG素材は、プロジェクト上位の`UI素材_Unity用/`にまとめました。HTML版では月の刻印コイン、取得光、HUDの飾り枠を`assets/`へ同梱しました。以前の`assets/ui/`内の簡易SVGは旧案です。

## 確定仕様との差分・未完成

- ステージマップとステージ選択を1画面に統合しています（詳細仕様書で許可された試作上の簡略化）。
- 魔女は専用カードの仮演出です。完成版のアニメーション・専用音声はありません。
- 進行中ゲームの保存、複数ステージ、タイムスコアは未実装です。ステージ最高スコアと音量設定を保存します。
- 曲線上の飛翔を出しやすくするため、坂の傾き・曲率・速度に応じた上向きの補助を加えています。平地で `Space` を離してもジャンプしません。
