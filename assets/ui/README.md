# 『猫は液体』B案 UI素材セット

`references/B_main/07_B案_デザインボード.png`の紺・金・月光の方向性に合わせ、ゲームで使えるように描き直した透過SVG。コインは採用済みの「月の刻印」。参照画像から切り抜いたものではなく、拡大しても使える独立したベクター素材です。

## 組み込み方

- 枠SVGは背景として使い、**文字・数値・ボタンの当たり判定はHTML側**に置く。本`2/3`、コイン`12/50`、スコア`4,520`、残機`×3`などを画像に焼き込まない。
- 停止危険ゲージは`danger-gauge-frame.svg`の空トラックに、CSSの可変幅の色帯を重ねる。元画像座標で充填部は概ね`x=178〜546, y=36〜54`。猫マーカーも残機アイコンを別要素で重ねる。
- コイン取得時は、取得したコインの**画面座標**に`icon-spark.svg`を重ね、約0.3秒で拡大・消失させる。小粒子は約0.5秒。`+100`は別の動的テキストで表示する。画面全体のフラッシュは使わない。
- コイン本体はワールド内に描画する。遠景ズームで小さくなりすぎる場合は表示径を制限する。アイコンと枠は必要ならCSSで縮小できる。
- 配置数と判定は`docs/次段階_コイン・スコア・残機_仕様案.md`を参照。現時点の約60枚はプレイテスト前の初期案。

このセットはUI素材の準備用です。ゲーム画面への組み込みとコイン・スコア・残機の処理は別工程です。
